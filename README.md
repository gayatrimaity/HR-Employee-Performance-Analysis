# HR Performance Analysis | Power BI Project

## Overview
This project presents an interactive HR performance dashboard built in Power BI to analyze employee productivity, attendance, achievement, and performance ratings across departments and managers.

## Objective
The dashboard is designed to help identify:
- overall employee performance trends
- department-wise differences
- manager-wise performance patterns
- monthly achievement variation
- data quality issues in performance classification

## Key Metrics
- Total Employees: 1000
- Average Attendance: 84.82%
- Average Achievement: 114.29%
- Performance Rating: 3.00

## Dashboard Highlights
- Department-wise attendance analysis
- Manager-wise achievement comparison
- Monthly achievement trend
- Performance category distribution
- Interactive filters for department, manager, category, and month

## Key Insights
- HR, IT, and Finance show the strongest achievement levels.
- Customer Service records the lowest achievement.
- Monthly performance is strongest in January, March, and April.
- Performance dips are visible in February, August, and November.
- Performance ratings are not always aligned with achievement patterns, suggesting scoring variation across teams.
- 121 records have blank performance categories, which should be treated as a data quality issue.

## Recommendations
- Standardize performance rating criteria across managers.
- Investigate low-performing departments, especially Customer Service.
- Review the cause of lower achievement in February, August, and November.
- Resolve blank performance category values to improve reporting accuracy.
- Use this dashboard for monthly performance tracking and manager review meetings.

## Tools Used
- Power BI
